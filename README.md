This was a hackweek that I did at VersionOne.  I wire up an old remote control car to s Raspberry Pi and integrated it with VersionOne (Agility).  This is the broken code. The last working code is in a company repo so I am going to clean it up and then port to Rust as an exercise.
The whole concept was for the car to drive around, grab tests from VersionOne, download them and perform them on itself.  I used the Rest-API and Python.  It was a wee bit lackluster since i probably could have gotten the sensors to respond better.  It was just POC of autonomous vehicle use with VersionOne.
